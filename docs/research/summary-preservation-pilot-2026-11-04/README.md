# 문장·역할 보존 개선의 짧은 후속 실험

## 실행 전 고정한 범위

- 사용자 선택: 평가용 경로만 개선. 운영 앱의 기본 검색·요약 정책은 변경하지 않는다.
- 판례 C 한 건, 키워드 K·E5 단독 S·하이브리드 H 각 한 번. 총 3개 완료 출력을 목표로 한다.
- 기존과 같은 Llama-3.2-1B-Instruct Q4_K_M, 컨텍스트 8,192토큰, 출력 상한 128토큰, 고정 seed 42를 사용한다.
- 새 프롬프트의 입력 상한은 1,536토큰이다. 초과 입력은 조용히 자르지 않고 실패한다.
- 기존 24개 실험의 capped/uncapped seed 42와 비교한다. 재실행·seed 평균·통계적 유의성 평가는 하지 않는다.
- 같은 판례를 이미 관찰한 탐색적 개발 실험이다. 독립 테스트셋 성능으로 주장하지 않는다.

## 변경 묶음

1. 기존 키워드·E5·RRF 검색기를 그대로 사용하되 검색 후보 전체의 순위를 받아 역할별 선택에 활용한다.
2. 판결요지/결정요지·이유·주문 영역에서만 완결 문장을 선택한다. 제목·참조판례 목록은 최종 근거에서 제외한다.
3. 법리·사실·판단은 서로 다른 의미 질문으로 검색하고 동일 문장의 재사용을 피한다.
4. 판단 문장이 연결어로 시작하면 바로 앞 원문 문장을 함께 복원한다. 모든 발췌는 원문 UTF-16 위치를 유지한다.
5. 한 문장 주문은 구조에서 직접 확보한다. 복수 문장 주문은 누락시키지 않고 이 작은 실험의 미지원 오류로 처리한다.
6. 문자 단위 재절단 대신 선택 문장 전체를 전달하고, 법리·사실·판단·주문의 네 항목과 부정·조건 보존을 지시한다.

E5 가중치·임계값·모델은 변경하지 않는다. 모든 구성에 같은 개선 정책을 적용하며,
새 결과는 위 변경 묶음의 효과이지 각 변경의 독립 인과효과가 아니다.

## 기록·판정

- 세 입력을 모두 구성하고 원문·모델 해시, 근거·검색 결과·프롬프트·실제 토큰 수를 manifest로 저장한 뒤 생성한다.
- 매 출력의 seed·토큰·종료 사유·시간을 원자적으로 저장한다. 규칙 기반 출력 보정·재생성은 하지 않는다.
- 같은 E5 provider를 S/H에서 공유한다. H는 S의 문서·질문 벡터를 재사용하므로 구성별 검색 시간을 독립 속도 비교로 해석하지 않는다.
- 기존 C1–C6 정답과 부분 점수 기준을 그대로 사용한다. 정답·평가 항목은 검색기·생성기에 전달하지 않는다.
- 원문 대조 AI 예비검수로 입력/출력 핵심 포함률, 부정 반전·미지지, 주문 보존을 구분한다.
- 네 항목의 출력 형식은 기존 요약과 다르므로 기존 파서 통과율과 직접 비교하지 않는다.

원자료와 실제 출력, 원인별 변경 설명, 비교 결과는 실행 후 별도 결과 문서와
[원문·출력 비교 문서](../RAG_Original_Output_Comparison_2026-11-04.md)에 추가한다.
