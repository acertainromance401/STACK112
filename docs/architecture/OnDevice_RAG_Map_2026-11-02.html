    RAG의 지식은 어디에 있나?

    사용자가 저장한 SwiftData 판례가 지식 원천입니다. 기존 카드는 키워드 방식이며 별도 연구 경로는 E5-base 문서 벡터를 융합합니다. 영속 벡터 DB는 사용하지 않습니다.

    참고 판례 ≠ 현재 판례의 정답

    다른 판례의 결론을 현재 사건의 사실로 섞지 않습니다. 현재 판례 필드를 우선하는 후처리도 유지됩니다. 프롬프트에 [R1]이 있다고 출력의 법률 주장이 검증된 것은 아닙니다.

    구현된 것과 남은 것

    별도 연구 경로에 청킹·인용 기초 검사·합성 평가셋·계측을 추가했습니다. 법률 전문가 검수와 실제 판례 품질·4GB 실기기 성능 측정은 남아 있습니다. 기존 OX는 기존 경로를 유지합니다.
